BioLab 요구사항 명세 v2.0
========================================
목적: 분자생물학 석사 신입생에게 PMC 논문 Methods 근거를 제공하는
한국어 AI 사수 선배. 기존의 로컬 RAG와 연구 데이터 보호 원칙을 유지한다.

아키텍처
- 프런트엔드: Next.js App Router, React, TypeScript
- 백엔드: Django 5.2 LTS, SQLite, 서버 세션 및 CSRF 보호
- 데이터: PMC XML → Methods 전처리 JSON → Chroma
- 임베딩: 로컬 BAAI/bge-small-en-v1.5
- 생성: Ollama lancard/korean-yanolja-eeve (환경 변수로 변경 가능)
- 브라우저 요청: Next.js 동일 출처 프록시 → Django

FR-01 수집: CLI로 PMC open access 논문을 수집한다.
FR-02 전처리: 리뷰/레터/에디토리얼/서평/코멘터리를 제외한다.
      Methods 500자 이상을 추출하고 1,000자 청크, 150자 overlap을 유지한다.
FR-03 출처: PMC숫자 PMCID와 논문 제목, 청크 ID 및 원문 링크를 보존한다.
FR-04 적재: 기존 Chroma 폴더는 보존하고 v2에 청크 ID upsert한다.
      같은 논문의 잔여 청크는 제거한다. 삭제된 파일의 자동 동기화는 범위 밖이다.
FR-05 검색: 대화 맥락을 참고하여 한국어 질문을 영어 검색문으로 정리한다.
      상위 2개 청크가 기본이며 1~6개 및 논문별 범위를 선택할 수 있다.
FR-06 생성: 친절한 한국어와 영어 전문 용어를 사용하며 제공된 근거에 한정한다.
      정보가 부족할 경우 이를 밝히도록 지시하고 조건·숫자의 창작을 금지한다.
      출처 검사는 PMCID 포함/허용 여부 검사이며 사실 검증을 보장하지 않는다.
FR-07 스트리밍: 진행 상태, 검색 근거, 토큰, 완료/실패를 NDJSON으로 전달한다.
FR-08 기록: 서버 SQLite에 세션별 대화를 저장·조회·삭제하며 Markdown으로 내보낸다.
FR-09 라이브러리: 제목/PMCID/초록 검색 및 Methods 전문을 열람한다.
FR-10 상태: Ollama 모델과 벡터 인덱스 준비 여부를 표시한다.
      임베딩 캐시 및 추론 성공 여부는 실제 질의에서 검증한다.

NFR-01 로컬 추론: 상용 외부 LLM API를 사용하지 않는다.
      최초 모델 설치와 논문 수집, 사용자의 원문 링크 열기는 인터넷이 필요하다.
NFR-02 비용: 로컬 오픈소스 소프트웨어로 구성하며 유료 API 비용을 발생시키지 않는다.
NFR-03 오류: 입력 길이 제한, CSRF, 세션 소유권, 실패 기록, 중복 생성 차단을 적용한다.
NFR-04 호환성: 기존 PMC XML·숫자 PMCID JSON을 읽고 기존 벡터 DB를 덮어쓰지 않는다.
NFR-05 검증: API·전처리 자동 테스트 및 프런트엔드 타입 검사/빌드로 검증한다.
NFR-06 운영 범위: 개인 PC loopback 배포. 다중 사용자 계정과 인터넷 공개 운영은 별도 단계다.

실행 절차, 환경 변수, API 규격, 운영 제한은 README.md를 따른다.
